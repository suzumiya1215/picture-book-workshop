# 新故事 10 步生成清单（每做一册走一遍）

> 配合《万能12页故事模板》使用。每一步都打勾才进入下一步。

- [ ] **1. 选主题**：从主题库选 1 个（本册只讲这一个）
- [ ] **2. 选主角**：固定班底里选 1 个当解决者 + 明确 TA 的梦想
- [ ] **3. 设麻烦**：谁 + 做了什么坏事/困难（反派要滑稽不要恐怖）
- [ ] **4. 设计线索**：意外掉落的证据（羽毛/脚印/纽扣/铃声…），后面推理必须用上它
- [ ] **5. 选排误对象 ×3~4**：每个配一个拟声词 + 符合身体的拒绝理由
- [ ] **6. 写重复句**：≤8 字，全册原样出现 ≥4 次
- [ ] **7. 填 12 页模板**：逐页填句式模板，控制每页 40–95 字
- [ ] **8. 朗读测试**：念出声录音回放，拗口就改；重复句试跟读
- [ ] **9. 自查清单**：
  - [ ] 起伏齐全：麻烦登场 → 线索意外 → 低谷 → 反转 → 圆满
  - [ ] 主题词只在点题页出现 1 次，不喊口号
  - [ ] 反派结局 = 承认错误 + 答应改正
  - [ ] 起伏齐全：麻烦登场 → 线索意外 → 低谷 → 反转 → 圆满
  - [ ] 主题词只在点题页出现 1 次，不喊口号
  - [ ] 结尾是诗意小诗，**不是亲子讨论题**（已删掉问答环节）
  - [ ] 0 抽象词、0 恐怖词
- [ ] **10. 出配图任务单**：每页一行"画面描述 + 出场角色 + 参考形象图编号"，
      存入本册文件夹 `05_新故事草稿/NN_书名/`（**一册一个文件夹**）
