# 万能 12 页故事模板（填空即用）

> 用法：先抄"第 0 步填空表"，再逐页照句式写。写完用 05 文件夹里的清单自查。  
> 这个公式来自《小青蛙的侦探梦》，已验证适合 3 岁，可无限套用。

---

## 第 0 步：一张填空表定全篇（5 分钟）

```
【主题】（毅力/勇敢/诚实/分享/耐心……每次只选 1 个）
【主角】＋【TA 的梦想】（例：小青蛙＋当大侦探）
【麻烦】谁，做了一件什么坏事/造成什么困难（例：壁虎偷东西）
【线索】意外掉落的证据（例：一条尾巴 → 可换：一根羽毛/半个脚印/一粒纽扣）
【排误对象 ×3~4】线索不属于谁，各自带拟声词和拒绝理由
【顿悟】主角如何推理出真相（观察特征 → 对上线索）
【改正】麻烦制造者怎么认错、怎么改
【夸赞句】"＿＿你真棒！你是我们的小英雄！"
【主题句】"只要有＿＿，＿＿就能成真。"
```

## 四个核心句式的"变体库"

**① 重复问句（全书灵魂，必须出现 ≥4 次）**

- 这是你的尾巴吗？／这是你的宝宝吗？／这是你的影子吗？／你能帮我吗？
- 设计要点：≤8 个字、每页原样重复、孩子能跟读。

**② 誓言句（P4，主角高光）**

- "我一定会抓住这个小偷的！案子会破，誓不为蛙！"
- 变体："誓不为喵！"（猫主角）／"不见不散！"／"做不到就不吃饭！"

**③ 夸赞句（P10，大团圆）**

- "你真棒！你是我们的小英雄！"
- 变体："你是我们的大医生！"／"森林里最勇敢的就是你！"

**④ 主题句（封底，讲给家长的一句话）**

- 只要有毅力，梦想就能成真。／只要敢开口，害怕就会变小。／诚实的孩子人人爱。

## 提问设计（"有一些简单的提问"的正确打开方式）

3 岁绘本的提问分三层，各放各的位置：

1. **剧情内提问**（推动故事）：主角问配角——"这是你的尾巴吗？"（P6-P7，每页 2 个）
2. **对读者的钩子**（悬念）："等等，难道是……"（P8 结尾，翻页前孩子会抢答）
3. **亲子讨论题**（书末彩蛋页，选做 2 个）：
   - "小青蛙问了哪四个朋友呀？"
   - "要是你一直找不到答案，你会放弃吗？"
   - "壁虎错了，他后来是怎么做的？"
