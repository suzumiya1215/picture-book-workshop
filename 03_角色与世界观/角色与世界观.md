# 角色与世界观（系列固定班底）

> 系列名：**咕噜咕噜动物村**（主场景）。同一批角色反复出现，每册换一个生活小麻烦。
>
> ⛔ **角色一律没有名字**——小刺猬就是小刺猬，小狗就是小狗，猫就是猫。  
> 故事正文里不出现"呱呱/飞飞/钉钉"这类名字。形象靠**中文锚句**锁定，不靠名字。

## 世界观：三层场景随便换

| 层级   | 场景                                 | 适合的故事              |
| ---- | ---------------------------------- | ------------------ |
| 主场景  | 咕噜咕噜动物村：池塘边的小村庄，有面包房、钟表店、水井、小木桥、院子 | 丢东西、做面包、生病、排队等日常故事 |
| 扩展场景 | 大森林（萤火虫谷、蘑菇坡、月亮湖）                  | 找路、夜行、迷路故事         |

**生活化原则**：题材优先取自日常——身体不舒服、东西忘了放哪、味道不对、夜里奇怪的声音、  
排不上队、植物长不好、走散了。不写离奇设定。

## 形象一致性五条铁律（配图不跑脸的关键）

1. **锚句逐字复用**：本页出场角色的中文锚句，一个字不改地前置到提示词最前面，以"—"结尾。
2. **风格指纹置顶**：上面那段风格前缀放在提示词第一句，全书每页都有。
3. **全书同一个 seed**：开画时定一次，写进 `配图/seed.txt`，所有页共用。
4. **种子图优先级**：① 角色基准像（锁脸）→ ② 第 1 页成品图（锁画风）→ ③ 无图则纯文生图。
5. **改单页时只放该页原图当种子**，不要混进基准像，否则会被重新洗一遍、改不动。

## 临时角色（路人）

- 每册可以加几个"只出现一两页"的动物（螃蟹、山羊、鹅、松鼠、小鸭子、蜜蜂、啄木鸟……）
- 临时角色不用画基准像，用场景插画带过
- 连续 2 册被用到的，升为常驻，补档案和基准像
- **新增常驻角色必须按六要素写锚句**：物种开头 / 主体色 / 眼鼻耳幼儿化 / 固定服装 / 绝对体型（不许写"比 XX 高"）/ 以"—"结尾
- 临时角色也没有名字，就叫"螃蟹""山羊""小鸭子"
