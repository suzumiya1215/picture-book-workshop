# 《小青蛙的侦探梦》原书解析

> 出处：培养大格局故事绘本（百花洲文艺出版社，全套 20 册，每册一个品格主题）  
> 本册主题：**毅力** ｜ 开本 1/48（约 184×130mm 小方本）｜ 正文 10 个内容面 + 封面封底  
> 解析目的：把这本"孩子爱听"的故事拆成可复用的零件，照着造新故事。

## 二、逐页功能表（这就是故事的骨架）

| 页   | 功能定位           | 剧情动作               | 写作技巧                                 |
| --- | -------------- | ------------------ | ------------------------------------ |
| 封面  | 梦想亮相           | 主角 + 梦想 = 书名       | "小青蛙的＋梦想"命名公式                        |
| P1  | **起**：麻烦登场     | 反派作案，偷走两样东西        | 开头一句"很久以前"直接入戏；"学会轻功和口技"一句话立住反派能力    |
| P2  | 承：麻烦升级         | 大家设了巡逻队也没用；反派还会伪装  | 反派"得意+小聪明"让后面失败更解气                   |
| P3  | **转**：线索掉落     | 作案时出意外，掉下关键证据（尾巴）  | 线索由"意外"产生，不靠运气硬给；"吓掉尾巴"带滑稽感，不吓人      |
| P4  | 主角立志           | 小主角站出来立誓言          | 誓言句式："我一定会……！……，誓不为蛙！"（可换成"誓不为X"）    |
| P5  | 行动开始           | 交代梦想由来，拿线索出发       | 一页一句过渡，节奏放快                          |
| P6  | 试错排误 ①②        | 拿线索挨个问：是你吗？→ 不是    | **重复句式第一次铺开**："这是你的尾巴吗？"；每个被问者带专属拟声词 |
| P7  | 试错排误 ③④        | 继续问，还被嘲笑           | 被问者的拒绝理由必须符合自身特点（下蛋、蹦跳），顺便做认知启蒙      |
| P8  | **低谷+坚持**（点题页） | 问不出来也没放弃，独自思考推理    | 主题词在这里落地："并没有放弃""不停地思考"；结尾留悬念"难道是……" |
| P9  | 高潮：真相揭晓        | 推理锁定目标，勇敢喝问；坏人认错改正 | 证据+推理，不是巧合；反派"认错+改正"，3岁结局不惩罚         |
| P10 | 圆满：梦想实现        | 大家夸赞，梦想达成          | 夸赞句式："你真棒！你是我们的小英雄！"                 |
| 封底  | 寓意封口           | 两句话总结              | 公式："只要有（主题词），（梦想）就能成真。"              |

## 三、六个可复用的写作技巧

1. **一条线索贯穿全篇**：掉落的"尾巴"既是意外，也是线索，也是后面推理的证据。新故事里换成"一根羽毛／半个脚印／一颗纽扣"都行。
2. **重复句式问 4 次**："这是你的尾巴吗？"——3 岁孩子听到第 2 次就会跟着念，这是全书最抓人的设计。重复句必须短（8 字左右）。
3. **每个配角配一个拟声词**：嘀嗒、唧唧、咯咯、汪汪——被问者先出声再说话，声音就是他的"身份名片"。
4. **拒绝理由=角色特征**：落地钟没有尾巴、蟋蟀要蹦跳、母鸡要下蛋。孩子能顺带学到"谁有什么、谁会什么"。
5. **主题词只点一次**：P8"并没有放弃"就是"毅力"，全篇不喊口号，靠情节托住。
6. **反派要可爱、结局要改正**：壁虎偷东西但滑稽（吓掉尾巴），最后"承认错误+答应改正"——符合 3 岁心理，不吓人、不惩罚。

## 四、节奏曲线

```
兴奋度：  中 ──╮        ╭──╮                    ╭── 高潮
          │  ╰──╮  ╭──╯  ╰──╮        ╭───────╯ ╰─ 圆满
低 ───────╯    ╰──╯（三次排误=平稳重复段）╯(低谷) 
页面：   P1  P2  P3(线索!)  P4(立志)  P5-7(重复段)  P8(低谷坚持)  P9(高潮)  P10(圆满)
```

重复段（P6-P7）故意"平"，是为了让 P8 低谷和 P9 反转更有力——**这就是"有起伏有转折"的秘密：平→落→起**。
