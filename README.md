# 绘本创作工坊

一套原创儿童绘本的创作工作台：从原书拆解、故事模板、角色世界观，到 17 个新故事的完整文字稿与制作规范。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `00_使用说明.md` | 整套流程的入口说明 |
| `01_原书解析/` | 对样板绘本的文本与结构拆解（12 页节奏怎么排） |
| `02_创作模板/` | 万能 12 页故事模板、新故事 10 步生成清单 |
| `03_角色与世界观/` | 角色设定、世界观规则、11 个角色的形象图 |
| `04_语言与制作规范/` | 语言风格、字数、句式、排版与印刷规范 |
| `05_新故事草稿/` | 17 个故事的目录，每个含 `story.json`（分页与文案）与 `_文字稿.md` |
| `06_跨页一致性与生图规范.md` | 跨页画风一致性、生图提示词写法 |

## 大件怎么备份

本仓库只收文本资产（约 19MB），以下内容被 `.gitignore` 排除：

| 类型 | 体积 | 为什么不入库 |
| --- | --- | --- |
| `*.pptx` | 273MB | 由 `story.json` 生成的排版产物，可重出 |
| `*_小册子单页版.pdf`、`*_骑马钉拼版.pdf` | 632MB | 打印用成品，随 PPT 重新导出 |
| 各故事 `配图/` | 505MB | 生图原图，按提示词可重生 |
| `_imgcache/` | 243MB | 生成过程的中间缓存 |
| `小册子单页版合集.zip` | 258MB | 超过 GitHub 单文件 100MB 上限 |

这些加起来约 2.2GB。要备份就直接整目录拷到移动硬盘或网盘；要进版本库，得先压 PDF 或改用 Git LFS。

## 约定

- 文字稿一律 Markdown，`story.json` 是排版脚本的唯一数据源。
- 新增故事按 `NN_故事名/` 建目录，`NN` 两位数递增。
- 改完文案先跑一遍 10 步生成清单，再重新导出 PPT。
