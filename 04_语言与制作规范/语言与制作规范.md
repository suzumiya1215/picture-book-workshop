# 3 岁语言规范 + 绘本制作规范

## 一、语言规范（3 岁，念出来好听）

### 字数与句子

| 项目   | 标准         | 原书实测    |
| ---- | ---------- | ------- |
| 每页字数 | 40–95 字    | 40–95 ✓ |
| 每页句数 | 2–5 句      | 2–5 ✓   |
| 单句长度 | ≤15 字，逗号切短 | ✓       |
| 全书正文 | 550–700 字  | 620 ✓   |

### 词汇白名单（多用）

- 具体名词：尾巴、铃铛、金币、枕头、脚印（孩子摸得到的）
- 动作动词：跳、冲、瞪、捂、扑、勾勒（一个动词一个画面）
- 拟声词：每册 ≥6 个，汪汪/咯咯/嘀嗒/啪嚓/呼噜/叮咚
- 重复词：重要的事情说 2 遍（"找呀找""想呀想"）

### 词汇黑名单（不用）

- 抽象词：智慧、勇气、责任、挫折 → 全部换成动作和情节
- 书面语：仿佛、似乎、竟然、顿时
- 恐怖/惩罚词：打死、关起来、狠狠地 → 用"吓了一大跳""羞愧地承认错误"

### 五个语法套路（照抄即出彩）

1. **三连排比**："偷走了睡鼠的金币、梅花鹿的银饰"→ 可加"花猫的铃铛"
2. **先声后人**：配角出场先出声——"咯咯咯，"母鸡捂着嘴笑起来
3. **顶针衔接**：句尾词当句头——"掉了一条尾巴。这条尾巴呀……"
4. **省略号悬念**：**最多 1 处**，而且不要每册都用（"等等，难道是……"用多了就成套话了）
5. **感叹收尾**：每页最后一句带"！"或"？"

## ⛔ 禁用台词与套路（用户红线，违反必重写）

### 禁用的句子

| 禁用                     | 原因           | 改成                |
| ---------------------- | ------------ | ----------------- |
| "我一定会……" / "我一定……"     | 太喊口号         | 换成动作："他先把灯提起来"    |
| "……誓不为蛙！" / 任何"誓不…"    | **用户明确说很尴尬** | 一律删掉，主角靠行动推进      |
| "他并没有放弃"/"他不停地…"这类励志套话 | 空            | 写具体动作："他又回教室找了一遍" |
| "他不怎么怎么"（否定式人物描写）      | 套路           | 直接写他做了什么          |

### 禁用的结构套路

1. **不要每页重复同一个问句**（原书"这是你的尾巴吗？"×4 那种）。  
   → 排查要换着写："先查…再查…""一个一个问过去""把土挖开看看"。
2. **不要每册都用同一个节拍**："找了半天没找着 → 蹲下来想啊想 → 难道是……"。  
   → **10 册里最多 1 册用**，其余换成"逐个环节查""按时间回想""走一遍原路"等不同方式。
3. **不要清一色侦探破案壳**（立志 + 出发 + 排误 + 反转 + 夸赞）。  
   → 情节起伏可以模仿，但题材要换：丢东西、味道不对、身体不舒服、怪声音、长不高、排队、走散……
4. **不要离奇设定**。贴近生活：生病、忘带伞、放错调料、盖子没拧紧、走错路。
5. **真相不要总是"某个角色干了坏事"**。优先用意外、误会、疏忽、需要帮助的人。

### 角色称呼规则

- **角色一律没有名字**：刺猬就是小刺猬，狗就是小狗，猫就是猫，蜻蜓就是小蜻蜓。
- 不用"呱呱/飞飞/钉钉/阿黄/咪咪婶婶/咕咕博士/溜溜/花花阿姨"这类名字。
- 需要区分时只写"小狗""大狗"，或加一句特征（"戴眼镜的山羊"）。
- 系列名仍可保留（咕噜咕噜动物村），但**故事正文里不出现角色名字**。

### 朗读测试（写完必做）

把稿子念出声录音，回放检查：① 有没有拗口的地方；② 孩子能不能在第 2 次重复句时接上话；③ 5 分钟内能不能讲完（3 岁专注力上限）。

## 二、制作规范（自制打印本）

### 开本与页数（★ 现行标准，脚本已固化）

| 项目   | 规格                         | 说明                     |
| ---- | -------------------------- | ---------------------- |
| 成品开本 | **A5 竖版 148.5 × 210 mm**   | 家用 A4 对折即得，打印机小册子功能直接吃 |
| 总页数  | **12 页**（封面 + P1–P10 + 封底） | 12 是 4 的倍数，小册子不补白页     |
| 作者   | **予欣爸爸 著 · 绘**（写给女儿予欣）     | 封面可带一行献词               |
| 适读年龄 | **不写**（已明确删除）              | —                      |

### 版面（用户逐条拍板）

- **图片为主**：图区 129.5 × 134 mm，顶部留 7 mm —— **占页高 64%**
- **正文用仿宋**：14.5–17 pt 按字数自适应；放在 14.45–19.40 cm 带内**垂直居中**，  
  **下方绝不留大片空白**（这是之前被打回的返工点）
- **页码公文式 `-2-`**：封面算第 1 页（不印号），正文从 `-2-` 起；  
  **奇数页靠右、偶数页靠左，绝不居中** —— 保证奇数页落在摊开后的右手页
- 每页固定元素只有页码；**不要角色名牌**（角色本来就没名字）
- 生图尺寸：内页 **1024×1024**（图区近正方形，裁切最小），封面 **1536×1024**

### 打印输出

- 出血：四边各 3mm；安全区：四边各 10mm 内不放文字
- 颜色：CMYK 或高饱和 RGB；纸张建议 157g 铜版纸（家用打印选相纸）
- 排版顺序（骑马钉）：封面-封底、P1-P10、封二-封三 按 PDF 拼版
- 家用 A4 打印：一张 A4 放 2 页（A5 拼），对折装订即可

### 每册固定配件

1. 封面：主角色大图 + 书名 + 副标题（"咕噜咕噜动物村 · XX篇"）+ 作者 + 献词一行
2. ⛔ **不要"亲子讨论题"页**（用户明确：结尾不要问答环节）
3. 封底：**小诗（4 行，居中）+ 一句话生活点 + 献词** —— 浪漫、诗意、童话式收尾；  
   末尾一行"副标题 ｜ 作者"
