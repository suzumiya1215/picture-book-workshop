## 08 《鹅的脖子睡歪了》｜睡歪了伸一伸，别急着害怕

- **类型**：身体误会（看着吓人，其实没事）
- **主角**：鹅（本册主视角）、小青蛙、大花猫、猫头鹰、小刺猬
- **状况**：鹅一早歪着脖子走路，脑袋偏向一边，看着像扭到了
- **排查链**：扭到了吗（能转能动，不像）→ 撞到了吗（昨天下雨没出门）→ 有人按她脖子吗（大家都说没有）→ 顺着脖子看，发现脖子僵僵的、有点酸 → 想起昨晚的睡姿
- **真因**：昨晚她枕着自己的翅膀睡，脖子歪着压了一整夜，睡麻了
- **小改变**：以后睡觉把脖子放平，醒来先伸一伸
- **生活点**：睡歪了伸一伸就好，别急着害怕
- **本册画面亮点（防无聊）**：清晨薄雾的村庄、鹅歪脖子走路时一排小动物跟着歪头学的滑稽画面、大家轮流当"镜子"照她姿势、鹅伸展脖子"咔"地正回来那一刻、结尾大家在院子里一起做早安伸展操

| P2  | 小青蛙猜是不是睡落枕，让她试着转一转——脖子能动能转。   |

## 09 《小鸭子自己走回家》｜记住路上的东西

- **类型**：走散认路（户外远行场景，画面最开阔）
- **主角**：小鸭子（主视角）、小蜻蜓（空中带路）、大黄狗（沿路找）、母鸡
- **状况**：集市上人挤人，小鸭子一低头看鞋，再抬头，大家都不见了
- **排查链**：喊人（没人应）→ 原地不动想妈妈的话 → 先找大石头（有）→ 过小木桥（有）→ 岔路口走错一次（越走越窄）→ 退回来换另一条 → 认出一排篱笆 → 到家
- **真因**：不是谁弄丢她，是她自己走岔了一次，靠记住的路标走回来了
- **小改变**：出门记住路上的记号（石头、桥、篱笆）
- **生活点**：记住路上的东西，走丢了也能自己找回家
- **本册画面亮点（防无聊）**：热闹集市全景、三层林间小路（空中蜻蜓带路/地面鸭子赶路）、岔路口三条小路的对比、篱笆后家门的那一束光

| P2  | 她站在原地喊了好几声，听见的全是别人的声音，心里有点慌。         |

## 10 《少了一个鸡蛋》｜先别急着怪别人

- **类型**：数量不对（误会同伴，情绪冲突最真实）
- **主角**：母鸡（主视角）、大黄狗（被怀疑的那个）、小青蛙、小刺猬、猫头鹰
- **状况**：母鸡数窝里的蛋，一、二、三……怎么少了一个？她又数一遍，还是少
- **排查链**：滚出去了吗（院子角落都找过，没有）→ 谁拿走了吗（小狗闻了闻，说没有别人的味道）→ 是不是自己记错了（昨天也是这个数）→ 把窝里的干草一根根叼开 → 最底下露出白白的一角
- **真因**：今天她下了两个，一个压在另一个下面，数的时候没看见，不是谁拿的
- **小改变**：以后数蛋先把干草翻一翻
- **生活点**：东西找不着时，先别急着怪别人，再仔细看看
- **本册画面亮点（防无聊）**：暖光鸡窝特写、母鸡一根根叼草的画面、蛋"滚"出来那一瞬、误会小狗时两人都委屈的表情、结尾两个蛋并排、圆滚滚发亮

| 页   | 一句话大纲（40–95 字正文待展开）                 |
| --- | ----------------------------------- |
| P1  | 母鸡每天下一个蛋。今天她数了数窝里的蛋——一、二、三……怎么少了一个？ |
| P2  | 她又数了一遍，还是少一个。她把窝边的草拨开找，没有。          |
| P3  | "是不是滚到外面去了？"大家在院子里找。花盆后面没有，台阶下面也没有。 |
| P4  | "是不是被谁拿走了？"母鸡看了一眼大黄狗。大黄狗低下头，很委屈。    |
| P5  | 小狗凑到窝边闻了闻，摇摇头："没有别的味道，谁也没来过。"       |
| P6  | 小青蛙说："那会不会是……数的时候没看清？"大家愣了一下。       |
| P7  | 母鸡蹲在窝边，把里面的干草一根一根往外叼，叼得很仔细。         |
| P8  | 叼到最下面的时候，露出白白的一角——还有一个蛋，压在草底下呢！     |
| P9  | 原来今天她下了两个，一个压在另一个下面。母鸡向大黄狗说了对不起。    |
| P10 | 母鸡把两个蛋并排放好，又数了一遍：一、二、三、四、五。一个都不少。   |

**封底**：东西找不着的时候，先别急着怪别人，再仔细看看。
