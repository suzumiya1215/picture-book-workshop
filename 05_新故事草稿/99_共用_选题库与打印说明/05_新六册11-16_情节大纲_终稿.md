# 换风格六册（11~16）· 24 页高密度版大纲 · 第 4 稿 · 待确认

> **第 4 稿修订（用户反馈：情节太少、节奏太慢、一页只有一两个动作）**
>
> - **病根**：第 3 稿把 10 个情节点铺成 22 页 → 每页只装 1 个小动作 → 灌水、拖沓。
> - **改法**：**每页塞 2~3 个事件/转折/新信息**。22 页 × 2.5 ≈ **每册 50~60 个情节点**。
> - **节奏变了**：不再是"慢慢展开"，而是**一件事接一件事往前推**，页页有新东西。
> - 页数仍为 24（封面 + 22 正文 + 封底）。
>
> **每页写作硬指标（本稿起执行）**
> 1. 每页**至少 2 件事**发生（做了A，又发生B）。
> 2. 每页**至少 1 个新信息**（新地点/新人物/新发现/新变化）。
> 3. **禁止**连续两页都在同一个地方做同一类事。
> 4. 每页画面仍有 5~8 个可讲元素（沿用第 3 稿要求）。

# 11《萤火虫只亮七晚》｜A 高饱和电影感

- **明线**：数日子（第一晚→第七晚）。
- **结尾**：萤火虫第七晚不亮，他埋在草坡插树枝；第二年夏天草坡又飞来许多。
- **本册情节点约 52 个**（平均每页 2.4 个）。

| 页 | 事件①+事件②（每页 2~3 件事） |
| --- | --- |
| P1 | 傍晚池塘边，小青蛙在数荷叶（**第1件事：日常**）。天暗下来，草丛"叮"亮了一下，他立刻蹲下拨草（**第2件事：发现光**）。 |
| P2 | 他看清是只萤火虫，屁股一亮一亮（**认出来**）。他伸手就扑，扑了个空，摔进泥里（**第一次失败**）。 |
| P3 | 他追过石桥、追过菜地，萤火虫忽左忽右（**追逐**）。他学乖了，屏住呼吸慢慢靠近，手心一拢——**抓住了**。 |
| P4 | 手心暖痒痒的，他高兴得在原地跳了三下（**喜悦**）。回家翻出玻璃罐，在盖上扎了三个小孔（**做容器**）。 |
| P5 | 罐子摆床头，绿光照亮枕头、被子、墙上的涂鸦（**安顿**）。他对着罐子讲了半天白天的事，讲到打哈欠（**第一次陪伴**）。 |
| P6 | **第二晚**一早他就去采最干净的露水（**新进展：喂食**）。又摘软叶子铺成小床，还用草茎搭了个小秋千（**做布置**）。 |
| P7 | 傍晚他带罐子去给小伙伴看，大家都围过来（**炫耀**）。小青蛙得意地说："我要养它一辈子！"（**立下心愿**） |
| P8 | **第三晚**，光好像暗了一点点（**发现不对**）。他眯眼凑近看，觉得是自己眼睛累了（**自我解释，失败**）。 |
| P9 | **第四晚**，光又暗了一点（**加重**）。他猜是罐子太闷，又扎了五个孔（**尝试解决①**），当晚光更弱了（**失败**）。 |
| P10 | **第五晚**，他换了个更大的罐子（**尝试解决②**）。又搬去窗台吹夜风（**尝试解决③**），光还是一样暗（**全失败**）。 |
| P11 | 他慌了一夜没合眼，把罐子捧在手心里（**恐慌**）。半夜他发现：光只有他眨眼的时候才好像亮一点（**错觉，更慌**）。 |
| P12 | 他去找小蜻蜓问（**求人①**）。小蜻蜓说"好像只能亮几天"，但也说不准，让他去问别人（**信息一半**）。 |
| P13 | 他跑去翻家里的旧书（**求人②/查证**）。书上画着萤火虫，旁边有小字，可他一个字也不认识（**失败**）。 |
| P14 | 他端着罐子走了很远的路去找猫头鹰（**求人③**）。猫头鹰眯着眼看怀表，说"你等等"（**被拖延，悬念**）。 |
| P15 | 猫头鹰终于开口："萤火虫天生就这样，亮七天，第七天就该休息了。"（**关键信息**）。小青蛙不信，问"那能不能让它多亮几天？"猫头鹰摇头（**希望破灭**）。 |
| P16 | 他回家数着日子重算一遍：第一晚、第二晚……（**自我验证**）。数到"第七晚"，他停住了，手有点抖（**确认**）。 |
| P17 | 他终于明白：不是罐子、不是露水、不是风（**排除一切**）。是**萤火虫自己的日子本来就短**（**真相落地**）。 |
| P18 | **第六晚**，他不再改造罐子了（**放弃挣扎**）。他把罐子放在窗台最好看的位置，陪它看了一晚上月亮（**陪伴升级**）。 |
| P19 | **第七晚**，光一点一点弱下去（**明线收束**）。他端罐子到草坡上，坐在旁边，一动不动地看着（**守护**）。 |
| P20 | 光小得像快灭的星星（**最弱**）。他张了张嘴想说什么，没说出来，就那么看着（**无声**）。 |
| P21 | 天亮，萤火虫不动了（**结束**）。他挖了个小坑埋好，插一根小树枝做记号（**安葬**）。 |
| P22 | 第二年夏天，那片草坡飞来好多萤火虫（**新生命**）。他蹲下来看了很久，说："我记得你。"（**记住**） |

**封底主题句**：有的东西只能陪你一小会儿，要好好记住它。
**给家长的一句**：这是孩子第一次遇见"再见"。不用说太多，抱着他坐一会儿就好。

# 12《小壁虎的红围巾》｜B 暗色绘本风

- **明线**：数朋友（问了四个）。
- **结尾**：回家对镜子说"我喜欢"，第二天自己戴着去玩。
- **本册情节点约 50 个**。

| 页 | 事件①+事件② |
| --- | --- |
| P1 | 早上奶奶坐在窗边织围巾，毛线滚到地上（**日常**）。奶奶把织好的红围巾往他脖子上一绕，说"给你的"（**礼物**）。 |
| P2 | 他围上围巾，跑到镜子前转了三圈（**兴奋**）。他发现围巾上有小流苏，就学着大人的样子把流苏捋顺（**细节**）。 |
| P3 | 他冲出家门，决定"让全村人都看看"（**目标**）。路上他特意走得慢慢的，等人来问他（**等待被看**）。 |
| P4 | 路过面包房，他在玻璃倒影里看见红围巾（**自我欣赏**）。他对着倒影笑了一下，还摆了摆头（**自恋小动作**）。 |
| P5 | 第一个去找大花猫（**明线：1**）。大花猫正把一盘面包端出炉子，屋里全是热气（**忙碌**）。 |
| P6 | 他站在门口清了清嗓子，等大花猫回头（**期待**）。大花猫头也没抬，只说"小心烫"，转身揉面去了（**落空**）。 |
| P7 | 第二个去找小刺猬（**明线：2**）。小刺猬盘腿坐在地上，把扎来的果子排成一排（**忙碌**）。 |
| P8 | 他故意在小刺猬面前走来走去（**制造机会**）。小刺猬只顾着数"一、二、三"，一个也没漏，没看他一眼（**落空**）。 |
| P9 | 第三个去找山羊（**明线：3**）。山羊挑着两桶水，走得飞快（**忙碌**）。 |
| P10 | 他拦住山羊想问一句（**主动出击**）。山羊只喊了声"借过"，水洒了他一脚，匆匆走了（**落空还受伤**）。 |
| P11 | 第四个去找小鸭子（**明线：4**）。小鸭子趴在池塘边，找自己的小木船（**忙碌**）。 |
| P12 | 他蹲下来陪小鸭子一起找，还帮着指方向（**讨好**）。小鸭子找到了船就跑了，还是没看他的围巾（**落空**）。 |
| P13 | 四个朋友四个都忙，他站在路口发愣（**总结落空**）。风把他的围巾吹到脸上，他第一次觉得围巾有点沉（**情绪转折**）。 |
| P14 | 他不死心，绕回面包房想再试一次（**第二次努力**）。可窗户关了，灯也暗了，人都走了（**彻底失败**）。 |
| P15 | 他坐在台阶上，解下围巾又系上（**反复纠结**）。系到第三次，手停住了（**心凉**）。 |
| P16 | 他小声问自己："是不是……不好看呀？"（**自我怀疑**）。没有人回答，路上一只鸟也没有（**孤独**）。 |
| P17 | 他想起奶奶织围巾的样子（**回忆**）。想起奶奶说"这是红颜色，最亮的那种"（**埋线回收**）。 |
| P18 | 他慢慢明白：今天大家都有自己的事，不是他不好，是他们没空看（**真相**）。 |
| P19 | 天黑了，他一个人往家走（**明暗转换**）。长长的路上，只有他的红围巾是亮的（**视觉隐喻**）。 |
| P20 | 回到家，他站到镜子前（**回到起点**）。把围巾一点点理好，流苏一根根捋顺（**自我照顾**）。 |
| P21 | 他看着镜子里的自己（**对视**）。轻轻说了一句："我喜欢。"（**点题**） |
| P22 | 第二天早上，他没有再去找人看（**放下**）。自己戴上围巾跑出去玩了，玩得满头大汗（**自在**）。 |

**封底主题句**：别人没注意你，不一定是你的错；你自己喜欢，也很要紧。
**给家长的一句**：孩子要的不只是夸奖，是确定地看你一眼。今天你抬头看他了吗？

# 13《木马变小了》｜B 暗色绘本风

- **明线**：数身高线。
- **结尾**：木马擦净盖布推到墙角，妈妈画了新线。
- **本册情节点约 50 个**。

| 页 | 事件①+事件② |
| --- | --- |
| P1 | 院角停着一匹旧木马，马鬃缺了一小块（**日常**）。小刺猬一进门就先去看它一眼（**牵挂**）。 |
| P2 | 他从小就骑它，小时候一跳就进去（**回忆**）。那时两只脚还够不到地，要晃半天（**细节**）。 |
| P3 | 每骑一次妈妈就在墙上画一道线（**惯例**）。墙上已经画了密密麻麻好多道（**时间感**）。 |
| P4 | 上一道线比下面那道高出半个手掌（**长高的证据**）。他还比过自己是不是又高了（**期待长大**）。 |
| P5 | 这天他一跳——屁股卡在外面（**意外**）。他滑下来愣住了，以为是没跳好（**不理解**）。 |
| P6 | 他退后几步又跳一次（**再试**）。还是进不去，他有点急了（**焦虑**）。 |
| P7 | 他围着木马转两圈，检查马腿马鞍（**排查①**）。木马好好的，眼睛还是那颗黑纽扣（**无异常**）。 |
| P8 | 他把木马搬到太阳底下晒（**排查②：以为是受潮**）。晒了一整天，来回翻面（**认真**）。 |
| P9 | 晒完再试，木头热乎乎的，还是进不去（**失败**）。他坐在地上直发愁（**受挫**）。 |
| P10 | 他请小青蛙来试（**求助①**）。小青蛙一蹦——也卡住了（**也不行了**）。 |
| P11 | 又请小猫来试（**求助②**）。小猫也进不去，三个人围着木马挠头（**都糊涂**）。 |
| P12 | 他们一起去找山羊（**求助③**）。山羊正戴老花镜修一把旧椅子（**忙碌场景**）。 |
| P13 | 山羊先量小刺猬（**测量**）。又量木马，量完拿笔在纸上算了算（**认真**）。 |
| P14 | 山羊放下尺子说："不是木马小了，是你长高了。"（**真相**）。小刺猬当场愣住（**惊讶**）。 |
| P15 | 他回头去看墙上的线，一道比一道高（**回头印证**）。数到最后一道，他停住了（**接受**）。 |
| P16 | 他低头看自己：袖子短了（**证据①**）。鞋子也挤脚了，昨天还磨了脚（**证据②**）。 |
| P17 | 他站到墙上最后一道线旁边比（**亲自验证**）。已经超过好多了，他心里咯噔一下（**确认**）。 |
| P18 | 他明白过来：木马一直没变（**排除**）。是他自己一天一天悄悄变大了（**真相落地**）。 |
| P19 | 他最后试了一次，退得很远跑过去（**告别式尝试**）。还是进不去，他喘着气站着（**接受**）。 |
| P20 | 他伸手摸摸木马的头（**告别**）。像小时候那样轻轻拍了拍（**温柔**）。 |
| P21 | 他拿布把木马擦得干干净净（**收拾**）。盖上布，慢慢推到墙角最里面（**收纳**）。 |
| P22 | 妈妈走过来，在墙上画了一道新线（**新记号**）。比上一道高了一截，他看了看木马又看了看线（**新开始**）。 |

**封底主题句**：长大是好事，可长大了，就有些小时候的东西玩不了啦。
**给家长的一句**：这一册可以配着墙上的身高线讲。孩子会懂的。

# 14《礼物没送到》｜C 强烈版画剪纸风

- **明线**：数露珠。
- **结尾**：露珠没了，门关了，叶子放门口，飞回家。
- **本册情节点约 52 个**。

| 页 | 事件①+事件② |
| --- | --- |
| P1 | 天没亮，草叶上躺着好多露珠（**日常**）。他一个个比较，挑出最大最圆的那颗（**选择**）。 |
| P2 | 今天是朋友生日，他要送露珠当礼物（**任务**）。他先在心里排好路线，盘算怎么飞最快（**计划**）。 |
| P3 | 他用宽叶子包露珠，折了三折（**制作**）。衔在嘴上试了试重量，还晃了晃脑袋看牢不牢（**检查**）。 |
| P4 | 天边露红，他出发了（**启程**）。他飞得很稳，一边飞一边回头看叶子（**紧张**）。 |
| P5 | 路上有挂水珠的蜘蛛网、打盹的瓢虫（**风景**）。他很想停下看看，但忍住了（**克制**）。 |
| P6 | 他飞过一片蒲公英（**新场景**）。风一吹，蒲公英种子满天飞，差点迷了他眼睛（**小波折**）。 |
| P7 | 天忽然阴了，哗啦啦下大雨（**意外**）。他赶紧躲进大蘑菇底下，翅膀全湿了（**受阻**）。 |
| P8 | 他在蘑菇下等，一滴两滴三滴（**明线：数**）。他探头看了三次，雨还是没停（**焦急**）。 |
| P9 | 雨终于停了，他抖抖翅膀立刻飞（**重启**）。可太阳一出来，叶子里露珠小了一圈（**第一次损失**）。 |
| P10 | 他飞得更急了（**加速**）。太阳越晒越烈，叶子里又漏掉一滴（**第二次损失**）。 |
| P11 | 飞过一片大湖，一阵风刮来（**新场景**）。露珠又漏一滴，只剩一半了（**第三次损失**）。 |
| P12 | 他低头看叶子，心里咯噔一下（**警觉**）。他改成侧着身子飞，想挡太阳（**想办法**）。 |
| P13 | 路上碰到鹅和小鸭子（**遇到人**）。他们喊他歇一歇，说"你都飞一天啦"（**劝阻**）。 |
| P14 | 他摇头没停："来不及啦，今天是他的生日！"（**坚持**）。他飞得更快，翅膀都酸了（**代价**）。 |
| P15 | 太阳越升越高，只剩浅浅一小汪水了（**继续损失**）。他急得翅膀直抖，飞得歪歪扭扭（**失控边缘**）。 |
| P16 | 他找了一片大树荫歇一口气（**最后一次尝试保住**）。可一停下来，太阳又追了过来（**无处可躲**）。 |
| P17 | 他努力飞得又快又稳（**拼尽全力**）。可露珠还是在一点一点变少（**无力**）。 |
| P18 | 天擦黑，他终于飞到朋友家门口（**到达**）。累得直喘气，翅膀都在抖（**疲惫**）。 |
| P19 | 他低头看叶子——只剩一道湿湿的水痕（**礼物毁了**）。他愣住了，半天没动（**崩溃**）。 |
| P20 | 他抬头：门关着，灯灭了（**二次打击**）。里面静悄悄的，生日已经过完了（**彻底错过**）。 |

# 16《老钟表走不动了》｜C 强烈版画剪纸风

- **明线**：数慢了几拍。
- **结尾**：钟能走但越走越慢，大家改看太阳鸡叫，猫头鹰还来上发条。
