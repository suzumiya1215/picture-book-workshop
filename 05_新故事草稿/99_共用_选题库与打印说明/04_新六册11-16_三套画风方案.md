# 换风格六册（11~16）三套视觉风格方案 · 必须一眼可辨

> 与既有 01~10「生活篇」的**柔和暖调水彩**形成鲜明对比。
> 三套风格之间也必须**一眼可辨**，不能混。

## 旧风格（对照组，新六册不再使用）
```
儿童绘本水彩插画,哑光粉彩质感,手绘柔和边缘,主色调锚定为 #FBF3E4 奶油底 + #8FBF6F 草绿 + #E8875B 暖橘,柔和暖色调,圆脸腮红,无刺眼投影
```

---

## 风格 A：高饱和电影感（用于 11、15）

**一句话辨识**：像动画电影概念图——强逆光、丁达尔光柱、有纵深的三层景深。

```
电影概念艺术风格儿童绘本插画,高饱和浓郁色彩,强烈戏剧性光影,逆光与丁达尔光柱,大气透视远景层次,浓重明暗对比与深色阴影,厚涂笔触与体积感,大面积色块堆叠,画面元素丰富饱满,前景中景远景三层纵深,微微颗粒质感,画面中不出现任何文字 —
```
- 关键词：`高饱和` `逆光` `丁达尔光柱` `大气透视` `三层纵深` `厚涂体积感`
- 色彩：朱红 / 靛蓝 / 鎏金，强对比
- 与旧差异：**不再平涂粉彩，而是有光影纵深和体积感的电影画面**

---

## 风格 B：暗色绘本风（用于 12、13）

**一句话辨识**：深蓝紫暗调、大面积阴影，一束冷光打在主角身上，孤寂感。

```
暗色调儿童绘本插画,深蓝紫与墨绿为主的低明度配色,大面积浓重阴影,单一冷光源聚光照射主体,强烈明暗比,颗粒纸质肌理,细密线描叠加暗部,孤独静谧氛围,画面元素丰富细节多,前景暗部中景主体远景虚化,冷灰色调,画面中不出现任何文字 —
```
- 关键词：`暗调` `深蓝紫` `大面积阴影` `冷光聚光` `颗粒纸肌理` `孤独静谧`
- 色彩：深蓝紫 / 墨绿 / 一点刺目亮色（如红围巾）
- 与旧差异：**整体偏暗，靠一束光讲故事**
- 与 A 差异：**A 是亮丽的强光电影感，B 是暗沉的聚光独照**

---

## 风格 C：强烈版画剪纸风（用于 14、16）

**一句话辨识**：粗黑轮廓、纯色平涂、几何色块拼贴，硬朗现代。

```
强烈版画风格儿童绘本插画,粗黑轮廓线勾边,纯色平涂无渐变,几何化色块拼贴,高对比撞色(墨黑/朱红/土黄/藏青),刮刻纹理与木刻刀痕,装饰性图案填充,扁平化构图,画面元素密集繁复,背景布满装饰纹样,强烈的平面设计感,画面中不出现任何文字 —
```
- 关键词：`粗黑轮廓` `纯色平涂` `几何色块` `木刻刀痕` `装饰纹样填充` `扁平密集`
- 色彩：墨黑 / 朱红 / 土黄 / 藏青，无渐变
- 与旧差异：**没有柔和边缘，全是硬边色块**
- 与 A/B 差异：**A、B 都有光影纵深，C 是完全扁平的平面设计**

## 四组辨识度自检

| 对比 | 一眼能否分辨 | 判据 |
| --- | --- | --- |
| 旧 vs 新三套 | ✅ | 奶油粉彩柔 vs 浓色硬朗 |
| A vs B | ✅ | A 亮、有光柱；B 暗、只有一束冷光 |
| A vs C | ✅ | A 有纵深光影；C 扁平硬边色块 |
| B vs C | ✅ | B 有明暗过渡；C 是纯色平涂 |

## 角色锚句处理

三套风格里**角色中文锚句仍然逐字复用**（保证角色不走形），只替换风格指纹前缀：
`[本册风格前缀] + [本册出场角色完整锚句] + [场景，元素丰富切题] + [负面词：文字,水印,多余人物]`

## 画面丰富度要求（用户新增，硬指标）

- 每页**至少 5~8 个可讲元素**（人物、器物、植物、建筑、光影、小动物、装饰）。
- 场景要**有逻辑**：和本页文字内容一一对应，**不堆无关东西**。
- 背景鼓励放**呼应剧情的连续小细节**（如第几晚的月亮形状、墙上第几道身高线、钟慢了几拍）。
