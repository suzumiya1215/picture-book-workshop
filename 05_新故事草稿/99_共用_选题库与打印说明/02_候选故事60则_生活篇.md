## 01 《小狗没力气》｜睡觉要盖好肚子

**一句话**：小狗今天趴在门口，连最爱的球都不追。大家一个一个猜原因、一个一个排除，最后发现他夜里睡觉没盖被子，着凉了。

- **排查链**：饿了吗（吃完还是没劲）→ 累了吗（睡一觉还是没劲）→ 摸额头发现烫 → 回想昨天在哪睡的 → 门口风口、没盖东西
- **生活点**：睡觉盖好肚子

| 页   | 内容                                   |
| --- | ------------------------------------ |
| P1  | 今天小狗趴在门口，尾巴也不摇。小青蛙扔过去一个球，他看都没看。      |
| P2  | 大家围过来。"是不是饿啦？"猫端来一块面包。小狗吃完了，还是趴着。    |
| P3  | "那是不是昨晚没睡好？"大家让他回窝躺一会儿。躺了半天，他还是没力气。  |
| P4  | 猫走过去，用爪子碰了碰他的额头——有点烫，鼻子也干干的。原来是生病啦。  |
| P5  | 那是怎么生病的呢？大家坐下来，一起回想昨天小狗都做了什么。        |
| P6  | 上午他在草地上跑，中午在池塘边玩水，傍晚帮母鸡把鸡蛋搬回家。       |
| P7  | 搬完鸡蛋，他躺在门口就睡着了，一直到天亮。夜里风从门口吹进来，凉凉的。  |
| P8  | 他睡着的时候，身上什么也没盖。肚子露在外面，吹了一夜的风。        |
| P9  | 猫赶紧拿来一条小被子给他盖上，又倒了一碗热水。小狗喝完，闭上眼睛睡着了。 |
| P10 | 第二天一早，小狗摇着尾巴跑出来，一口气追了三个球。大家都笑了。      |

**封底**：睡觉要盖好肚子。风从门口吹进来的时候，也要记得挪个地方。  
**问答**：① 小狗为什么没力气？ ② 睡觉前要记得做什么？

## 02 《刺猬的雨伞不见了》｜走之前回头看一眼

**一句话**：放学下雨，小刺猬发现伞不见了。他把今天去过的地方一个一个找过去，最后在面包店的柜台边找到了。

- **排查链**：教室（没有）→ 公交站（没有）→ 饭堂（没有）→ 躲雨时抬头看见柜台上的伞
- **生活点**：离开一个地方前回头看一眼

| 页   | 内容                                     |
| --- | -------------------------------------- |
| P1  | 放学的时候下起雨来。小刺猬一摸书包——糟了，伞不见啦。            |
| P2  | 他站在屋檐下，把今天去过的地方想了一遍：教室、公交站、饭堂，还有面包店。   |
| P3  | 先回教室。课桌底下没有，椅子后面也没有，讲台边空空的。            |
| P4  | 再去公交站。长椅上没有，站牌下面没有，地上只有几片湿叶子。          |
| P5  | 又跑到饭堂。桌子底下没有，放碗的架子旁也没有。刺猬的肚子咕咕叫起来。     |
| P6  | 雨越下越大。他坐在面包店门口躲雨，一抬头——柜台上有一把伞，和他的一模一样。 |
| P7  | 猫从里面探出头："这把伞在这儿放了一下午啦，我还以为是客人忘的呢。"     |
| P8  | 刺猬想起来了：下午他来买面包，两只手都拿着东西，就把伞放在柜台边上了。    |
| P9  | "下次走之前，回头看一眼。"猫把伞递给他，又塞给他一个热面包。        |
| P10 | 刺猬撑开伞走进雨里。伞是干的，面包是热的，他一路走一路笑。          |

**封底**：走开之前回头看一眼，东西就不容易丢。  
**问答**：① 刺猬的伞最后在哪儿？ ② 你有没有忘过东西？是怎么想起来的？

## 03 《今天的面包是咸的》｜一步一步看清楚

**一句话**：面包店今天的面包全是咸的。店里几个动物按自己负责的那一环一个一个查，最后发现是螃蟹把盐当成糖了。

- **排查链**：揉面（没问题）→ 烤炉（没问题）→ 装盘（没问题）→ 放糖那一环 → 两个罐子长得一样
- **生活点**：长得一样的东西要分开摆、做事情一步步看清楚

| 页   | 内容                                       |
| --- | ---------------------------------------- |
| P1  | 面包店今天排了好长的队。第一个客人咬了一口，愣住了："今天的面包，怎么是咸的？" |
| P2  | 猫赶紧尝了一口，真的咸。她把今天的面包全端进后厨，从头查起。           |
| P3  | 先查揉面。揉面的山羊说："面是我和的，只有面粉和水，别的什么也没放。"      |
| P4  | 再查烤炉。烤炉的鹅说："火候和每天一样，我一直在旁边看着呢。"          |
| P5  | 又查装盘。装盘的松鼠说："我只负责把面包放进篮子，什么也没加呀。"        |
| P6  | 那就剩最后一环了——放糖。今天负责放糖的是螃蟹，两只大钳子正忙个不停。      |
| P7  | 螃蟹举起两个罐子，一个写着"糖"，一个写着"盐"。两个罐子长得一模一样。     |
| P8  | "我今天拿的是左边这个。"螃蟹指了指。大家凑过去一看——左边那个，是盐。     |
| P9  | 原来两个罐子一样高、一样白，螃蟹今天没戴眼镜，抓错了。              |
| P10 | 猫重新烤了一炉，甜甜的香味飘满整条街。螃蟹给两个罐子换成了不一样的颜色。     |

**封底**：做事情一步一步看清楚，长得一样的东西要分开放。  
**问答**：① 面包为什么变咸了？ ② 螃蟹后来想了什么办法？

## 04 《夜里的咚咚声》｜先去看看，再决定害不害怕

**一句话**：夜里总有"咚咚"的声音，大家不敢睡。一个一个地方查过去，最后发现是晾在院子里的木勺被风吹着敲水桶。

- **排查链**：是门吗（不是）→ 是窗吗（不是）→ 是楼梯吗（不是）→ 提灯到院子里听 → 木勺撞铁桶
- **生活点**：听见怪声音先看看，多半是小东西在响

| 页   | 内容                                      |
| --- | --------------------------------------- |
| P1  | 这几天夜里，院子里总有"咚、咚、咚"的声音。小青蛙躲在被子里，怎么也睡不着。  |
| P2  | 第一晚，大家以为有人敲门。猫打开门——外面空空的，只有月亮。          |
| P3  | 第二晚，声音又来了。这回像是窗户。大家把窗户关紧，声音还在响。         |
| P4  | 第三晚，母鸡说："会不会是楼梯？"大家把楼梯上的东西全搬走，声音还是"咚咚"。 |
| P5  | 大家干脆不睡了，提着灯一起到院子里听。声音从厨房那边过来，一下，又一下。    |
| P6  | 走近一看：一根木勺挂在晾衣绳上，风一吹，勺子就撞在旁边的铁水桶上。       |
| P7  | 风大一点，撞得重一点；风小一点，撞得轻一点。原来是这样。            |
| P8  | 猫把木勺取下来，放回碗柜里。院子里一下子安静了。                |
| P9  | 那一夜，谁也没被吵醒。第二天早上，大家都在饭桌上打哈欠。            |
| P10 | 母鸡笑着说："以后听见怪声音，先去看看，再决定害不害怕。"           |

**封底**：听见奇怪的声音，先去看看是什么，就不那么害怕了。  
**问答**：① "咚咚"声其实是什么？ ② 害怕的时候可以怎么办？

## 05 《面包店今天没开门》｜迟到的人可能正在帮忙

**一句话**：大家约好早上在面包店碰头，等了很久猫还没来。一路找过去，发现她在山坡下帮小鸭子修车。

- **排查链**：睡过头了吗（屋里没人）→ 路上摔着了吗（闻到面粉味）→ 顺着洒落的面粉找 → 山坡下的坏车
- **生活点**：别人迟到时，先别急着生气

| 页   | 内容                                    |
| --- | ------------------------------------- |
| P1  | 今天大家约好在面包店吃早饭。可太阳都升得老高了，店门还关着。        |
| P2  | "是不是睡过头啦？"小青蛙趴在窗户上看，里面黑黑的，一个人也没有。     |
| P3  | "是不是路上摔着了？"小狗鼻子最灵，他沿着路一直闻，闻到了面粉的味道。   |
| P4  | 大家顺着路找。路边有洒落的面粉，一路延伸到山坡下面。            |
| P5  | 山坡下，猫正蹲在一辆小推车旁边。车上装满了面粉袋，一个轮子掉下来了。    |
| P6  | 车上还坐着一只小鸭子，她的脚受伤了，正抱着自己的腿。            |
| P7  | 原来小鸭子的车坏在半路，猫看见了就停下来帮她。面粉撒了一地。        |
| P8  | 大家一起来帮忙：小狗扶着车，山羊找来一根木棍当轮子，刺猬把面粉一袋袋装好。 |
| P9  | 推车修好了，大家一起把车推回面包店。猫打开门："今天的面包，我请客。"   |
| P10 | 热面包端上桌，小鸭子的脚也不那么疼了。大家说："这顿早饭等得值。"     |

**封底**：有人迟到的时候，可能正在路上帮别人呢。  
**问答**：① 猫为什么没按时开门？ ② 大家是怎么帮上忙的？

## 06 《向日葵不长了》｜挤在一起谁也长不大

**一句话**：小院里的向日葵苗一直不长。大家一个一个排除原因，最后发现是几棵苗种得太挤了。

- **排查链**：没浇水吗（土是湿的）→ 没太阳吗（搬到院子中间也没用）→ 有虫吗（叶子好好的）→ 挖开土看 → 根挤成一团
- **生活点**：植物要留空间

| 页   | 内容                                       |
| --- | ---------------------------------------- |
| P1  | 春天，大家在院子里种了几棵向日葵。别的苗一天天长高，只有角落那几棵，还是那么矮。 |
| P2  | "是不是没浇水？"小青蛙每天来浇，土一直是湿的，可苗还是没长。          |
| P3  | "是不是晒不到太阳？"大家把花盆搬到院子中间，一整天都有太阳，还是没长。     |
| P4  | "是不是有虫子？"猫一片叶子一片叶子地看，叶子绿绿的，一个洞也没有。       |
| P5  | 大家蹲在那儿发愁。刺猬说："那我们把土挖开看看呢？"               |
| P6  | 小心地挖开一点土——下面全是根，几棵苗的根缠在一起，挤得满满的。         |
| P7  | 原来一个盆里种了五棵，根没地方伸，谁也长不大。                  |
| P8  | 大家把其中三棵小心移出来，种到另外的盆里，只留两棵在里面。            |
| P9  | 过了几天，留下的两棵开始长高了；移走的那三棵，也一天比一天精神。         |
| P10 | 夏天的时候，院子里开了五朵向日葵，一朵比一朵高。                 |

**封底**：挤在一起谁也长不大，留出地方，大家都能长高。  
**问答**：① 向日葵为什么长不高？ ② 大家想了什么办法？

## 07 《井边排好队》｜排好队反而更快

**一句话**：水井前大家抢着打水，桶撞翻了谁也打不上。后来排好队，一个接一个，反而快了一半时间。

- **起伏链**：抢 → 撞翻 → 安静 → 有人提议排队 → 一个接一个 → 更快
- **生活点**：排队

| 页   | 内容                                  |
| --- | ----------------------------------- |
| P1  | 天热了，井边的队伍排得老长。大家都想先打水。              |
| P2  | 山羊往前挤，鹅伸长脖子往前挤，小狗干脆跳到了最前面。          |
| P3  | 你挤我，我挤你。只听"哐当"一声，三只桶撞在一起，水全洒了。      |
| P4  | 井边一下子安静了。大家看着湿漉漉的地面，谁也没打上水。         |
| P5  | 母鸡在后面等了很久，她小声说："要不……我们排好队？"         |
| P6  | 大家站成一排。山羊第一，鹅第二，小狗第三，母鸡最后。          |
| P7  | 山羊打完，退到一边；鹅打完，也退到一边。一个接一个，谁也不用挤。    |
| P8  | 轮到小狗的时候，他一会儿就打满了一桶。他发现：这样反而快多了。     |
| P9  | 最后轮到母鸡，她的桶也装满了。大家数了数，一共才用了平时一半的时间。  |
| P10 | 从那天起，井边每天都排着整整齐齐的队。打完水，大家还会互相帮着抬一抬。 |

**封底**：排好队，一个接一个，谁也不慢，还更快。  
**问答**：① 一开始大家为什么打不上水？ ② 排队以后有什么不一样？

## 08 《蜂蜜罐空了一半》｜盖子要拧紧

**一句话**：蜂蜜罐一夜之间少了一半。大家以为被人吃了，问了一圈都不是，最后发现是盖子没拧紧，蜂蜜顺着罐子流走了。

- **排查链**：谁半夜来吃的（都说没有）→ 看罐子外面（黏的）→ 一条痕迹流到柜底 → 盖子歪着没拧紧
- **生活点**：盖子拧紧

| 页   | 内容                                |
| --- | --------------------------------- |
| P1  | 早上，蜜蜂打开蜂蜜罐——咦，昨天还是满满的，今天少了半罐。     |
| P2  | "是不是谁半夜来吃的？"大家你看看我，我看看你，都说没有。     |
| P3  | 小青蛙说："我晚上睡得早。"小狗摇着尾巴："我在窝里待了一整夜。" |
| P4  | 刺猬也摇摇头："我晚上只吃果子，蜂蜜太甜啦。"           |
| P5  | 那就奇怪了。蜜蜂把罐子从柜子里抱出来，放到桌上仔细看。       |
| P6  | 罐子外面黏黏的，一条亮亮的痕迹从罐口一直流到柜子底。        |
| P7  | 再看盖子——没拧紧，歪着扣在罐口上。蜂蜜就是从这儿一点一点流走的。 |
| P8  | 原来昨天装完蜂蜜，蜜蜂急着出门，盖子只随手搭上了。         |
| P9  | 大家把柜子擦干净。蜜蜂把盖子拧紧，还在外面套了一个小布兜。     |
| P10 | 第二天早上，蜂蜜还是满满一罐。蜜蜂笑着说："以后我天天都拧结实。" |

**封底**：用完东西把盖子拧紧，就不会白白浪费啦。  
**问答**：① 蜂蜜是怎么少的？ ② 蜜蜂后来做了什么？

## 09 《小鸭子自己走回家》｜记住路上的东西

**一句话**：小鸭子在集市上和大家走散了。她照着记得的路标一个一个往回走，走岔了一次又退回来，最后自己到了家。

- **起伏链**：走散 → 慌 → 想起妈妈的话 → 找大石头 → 过小木桥 → 走错一条路 → 退回来 → 到家
- **生活点**：记住路标

| 页   | 内容                                   |
| --- | ------------------------------------ |
| P1  | 今天集市好热闹。小鸭子跟在大家后面，一低头看鞋子，再抬头——人都不见了。 |
| P2  | 她站在原地喊了好几声，听到的全是别人的声音。她有点想哭。         |
| P3  | 这时候她想起妈妈说过的话："记不住路，就记住路上的东西。"        |
| P4  | 来的时候，她记得先经过一座小木桥，桥边有一块大石头，石头上开着小红花。  |
| P5  | 小鸭子转过身，先找那块大石头。她走了一段，看见了——石头在那儿！     |
| P6  | 过了石头是小木桥。她小心翼翼地走过去，桥板"咯吱咯吱"响。        |
| P7  | 过了桥，她走岔了一次：前面有三条路，她挑了中间那条，越走越窄。      |
| P8  | 她停下来看了看：这条路没有来时的味道。她退回去，改走左边那条。      |
| P9  | 左边这条路她认得——路边有一排矮矮的篱笆，篱笆后面就是她家。       |
| P10 | 小鸭子推开院门，大家正急得团团转。看见她，全都围了上来。         |

**封底**：记住路上的东西，走丢了也能自己找回家。  
**问答**：① 小鸭子记住了哪几个路标？ ② 走错路以后她是怎么做的？
